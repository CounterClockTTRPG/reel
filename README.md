# Reel

Narrated tour and tutorial videos of web applications, for YouTube, from scripts kept in a repository. A film is a
script and a config; `reel` records it in a browser, cuts the waits, adds the narration and the music, and packages it
for YouTube, and `reel review` shows every scene for approval first.

Not built yet: the requirements are in [docs/requirements.md](docs/requirements.md), the backlog in Tasker (project
**REEL**). It grows out of `~/claude/delve-video`.
